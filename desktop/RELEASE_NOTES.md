# VideoDL Desktop 0.5.1

粘贴一行、多行链接或分享文本，自动识别并按来源链接分组。每条链接的标题、视频、音频、封面和画质选择留在自己的组内，按输入顺序排列。

- 相同地址按首次出现去重，单批最多 200 条；编辑和粘贴保留原结果，点击“提取链接”或按 `Ctrl+Enter` 才开始新批次。
- 组头显示序号、来源地址和内容数量，提供“选择本组”和“下载本组”；同一链接返回多个视频或分P时，全部留在原组内。
- 等待、提取中和失败显示在对应组内；失败可单独重试，其他组继续处理。
- 搜索、类型筛选、组内下载和跨组批量下载共用筛选范围，逐行画质与勾选保留；不同链接的相同标题也能分别下载。
- 异步返回时只插入对应组的新行，继续复用其他组的控件，保留画质选择及输入焦点。
- 新批次替换旧结果和未运行队列，正在下载的任务继续；成品仍直接保存到指定目录，同名自动编号。
- 兼容旧设置、队列和结果记录；旧结果按链接首次出现顺序恢复分组。沿用明暗主题、B站登录和后台解析缓存。

下载 `VideoDL-Desktop-0.5.1-windows-x64.zip`，完整解压后双击 `VideoDL Desktop.exe`。保留同目录下的 `_internal` 文件夹。设置、B站登录和下载记录继续沿用。

Python、FFmpeg、ffprobe 和 Node.js 随包提供。自动化维护说明见源码中的 `desktop/AUTOMATION.md`。
