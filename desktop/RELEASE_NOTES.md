# VideoDL Desktop 0.3.0

本版统一各平台的提取与下载流程，并修复临时标题变化导致的“所选条目已经变化”下载失败。

- 视频行直接显示 `1080p-MP4` 等画质下拉框；每行独立选择，批量下载遵循各行选择，默认最高可用档。
- 根据实际返回的格式列表、HLS/DASH 清单及独立音视频资源生成选项；音频保持原始音轨，封面保存原图。
- 自动获取真实标题，更新抖音链接识别，支持搜索页 `modal_id`、标准视频链接及短链接。
- 提取与下载复用后台进程和解析缓存，减少重复加载和重复请求；媒体地址失效时自动刷新一次。
- 按格式记录下载完成状态，切换画质后可另行下载；兼容旧版本设置、队列和提取记录。
- 后备解析采用确定顺序，单链接提取上限 60 秒；取消及退出时清理对应后台进程和媒体工具。

下载队列支持 1–3 个并发任务、取消、失败重试、暂停与历史恢复。同名文件自动编号。

下载 `VideoDL-Desktop-0.3.0-windows-x64.zip`，完整解压后双击 `VideoDL Desktop.exe`，保留同目录下的 `_internal` 文件夹。Python、FFmpeg、ffprobe 和 Node.js 随包提供。

来源实际提供的版本会显示在列表中；部分资源当次仅提供一个可用版本。解析及下载均自动处理。

自动测试覆盖真实 HLS/DASH 画质下载、FFprobe 分辨率与音轨核对、缓存复用与过期、旧记录恢复、行内画质选择及 Windows 后台进程退出。

使用说明及分支维护说明位于桌面版源码的 `desktop/` 目录。完整包附带 `LICENSE.txt`、`THIRD-PARTY-NOTICES.txt` 和构建记录。
