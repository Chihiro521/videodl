# VideoDL Desktop 0.5.0

界面采用参考 cobalt 的黑白风格、等宽字体和窄侧栏。首页居中输入链接，开始提取后输入区收紧到顶部，结果列表获得更多空间。

- 支持跟随系统、浅色和深色主题；菜单、画质下拉框、设置和队列统一切换。
- 视频、音频、封面继续独立选择，类型使用分段按钮筛选；每条视频可直接选择实际可用画质。
- 下载进度局部更新，保留滚动位置、输入焦点、勾选和画质；滚轮经过画质框时滚动列表。
- 视频、原始音轨和封面直接保存到指定目录，同名自动编号；并发同名下载保留各自文件。
- 开始新一批提取时清空旧列表及未运行队列，正在下载的任务继续；旧文件和历史路径保留。
- 沿用 B站扫码登录、后台解析缓存、自动下载和失败重试。

下载 `VideoDL-Desktop-0.5.0-windows-x64.zip`，完整解压后双击 `VideoDL Desktop.exe`。保留同目录下的 `_internal` 文件夹。设置、B站登录和下载记录继续沿用。

Python、FFmpeg、ffprobe 和 Node.js 随包提供。自动化维护说明见源码中的 `desktop/AUTOMATION.md`。
