# VideoDL Desktop 0.2.0

集中式下载工作台：批量提取链接，在结果列表中选择视频、音频和封面，再直接下载。

- 新的白色侧栏、蓝色主按钮、结果表格与固定保存路径栏。
- 每条链接分别提取，结果按视频、音频、封面列出；支持搜索标题、按类型筛选、全选、勾选下载和逐行下载。
- 结果行直接显示等待、下载进度和完成状态，完成后可打开文件所在位置。
- 支持停止提取、重试失败链接、提取后按偏好自动下载。
- 同一条目的多种内容合并下载；多分P按条目标识匹配，避免列表变化时取错内容。
- 提取结果、旧版设置和下载记录继续保留；包含完整 GUI 提取与下载的打包验证。

下载队列继续支持 1–3 个并发任务、取消、失败重试、暂停与历史恢复。音频优先下载独立音轨，或从媒体中提取原始音频；同名文件自动编号。

下载 `VideoDL-Desktop-0.2.0-windows-x64.zip`，完整解压后双击 `VideoDL Desktop.exe`。Python 运行环境、FFmpeg、ffprobe 和 Node.js 随包提供。

视频画质由上游解析器选择。音频输出保持源编码。自动测试覆盖真实 HTTP 下载、批量提取与选择、原始音轨一致性、队列恢复、打包窗口启动，以及完整 GUI 提取下载流程。各平台解析可用性取决于上游和网站接口。

平台实测：Bilibili 普通视频的标题与封面解析、封面保存、视频下载和原始音轨提取均通过。其余平台继承上游解析器，尚未逐一实测。

使用说明及分支维护说明位于桌面版源码的 `desktop/` 目录。完整包附带 `LICENSE.txt`、`THIRD-PARTY-NOTICES.txt` 和构建记录。
