# VideoDL Desktop 0.5.3

## YouTube Music 单曲适配

增加桌面侧 YouTube Music 适配器。`music.youtube.com/watch?v=...` 会转换为上游 YouTube 客户端可识别的标准视频地址，结果在界面中作为音频显示，并沿用原始音轨、标题、封面和现有保存方式。播放列表地址暂按单曲链接处理，需逐条添加。

窗口底部新增“保存方式”，单条与批量下载都可选择：

- **直接保存文件**：视频、原始音轨及封面直接放到保存位置。
- **按作品分文件夹**：以作品标题建目录，同一作品的三类文件放在一起；不同作品同名时自动编号。
- **按类型分文件夹**：视频、音频、封面分别集中保存，只创建需要的分类。

切换上方“音频”“视频”“封面”后，批量按钮直接显示相应内容，例如“批量下载音频”。搜索与勾选继续生效，每条视频仍按自己的画质下载。

保存方式会记住上次选择；任务加入队列时固定保存方式，之后切换选项不改变已有任务。重试继续使用原方式和作品目录，旧设置及旧任务默认直接保存。

解析器工作目录及下载、合并、提取中间文件移出成品目录。跨磁盘复制在保存位置外完成，文件就绪后才放入成品目录；取消和失败会清理临时内容及本次新建的空目录，保留已有文件。

下载 `VideoDL-Desktop-0.5.2-windows-x64.zip`，完整解压后运行 `VideoDL Desktop.exe`，保留旁边的 `_internal` 文件夹。沿用已有设置、B站登录和下载记录。
