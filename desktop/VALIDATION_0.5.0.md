# v0.5.0 验证记录

本版改动集中于桌面布局、主题、界面刷新和文件输出。上游解析源码继续沿用原版本。

## 界面与兼容

- Windows 11，980×680 和 1180×800，100%、125%、150% 缩放。
- 覆盖居中首页、批量结果、筛选无匹配、全部失败、恢复历史结果、浅色和深色设置。
- 980×680 结果列表不产生横向滚动条。设置页使用纵向滚动，按钮和主题选项可见。
- 检查同一媒体重新返回元数据后，复用的勾选、画质及下载按钮读取最新条目；列表不因进度更新替换控件。
- 滚轮经过关闭的画质框滚动列表；已展开的画质菜单保留正常滚轮操作。

## 刷新性能

本机同一组 100 条媒体、300 行结果、默认窗口，五轮取中位数。计时包括一次事件循环处理，属于界面局部刷新测量，不代表网络提取耗时。

| 场景 | 修改前 | v0.5.0 |
| --- | ---: | ---: |
| 重复刷新同一结果列表 | 1534.36ms | 11.95ms |
| 连续调用状态刷新 100 次 | 4899.41ms | 36.22ms |

进度事件按 75ms 合并，搜索按 150ms 合并。终止状态立即刷新；勾选、画质和滚动位置保留。

## 媒体与输出

本地 HTTP 服务提供真实 MP4、AAC/M4A 和 PNG，测试校验视频与封面的 SHA-256，以及提取前后的音频包哈希。三种成品直接出现在选择的目录中，完成后没有按标题创建的子目录。

八个并发同名文件发布保留全部内容，并保留预先存在的文件；中文文件名按 `标题 (1).mp4` 等自动编号。取消测试检查后台进程停止及临时目录清理。

## 检查与发行

源码回归覆盖 51 项测试，4 项仅供打包 exe 运行；自动化维护另有 11 项测试。Windows 发行流程还执行 6 项 exe 回归：诊断、后台输出、无外部 Python 启动、完整 GUI 下载、HLS 和 DASH 指定画质。

便携包由现有隔离构建流程生成，发行草稿在校验版本、提交和 ZIP 哈希后创建。实际检查结果保存在 PR 与 Actions 记录中。
