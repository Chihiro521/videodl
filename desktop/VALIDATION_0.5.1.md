# v0.5.1 验证记录

本版增加来源链接分组，沿用现有 PySide6 界面、媒体标识、画质、解析缓存及下载内核，上游源码未改动。

## 输入与来源归属

- 单行、多行、分享文本、重复地址，以及 0／1／200／201 条输入边界。重复链接按首次出现去重，超限与无链接时保留原结果及队列。
- 使用可控的后台返回顺序，让第二组先完成、第一组后完成；同标题、相同媒体编号、多个分P仍保持各自来源和原始条目顺序。
- 每条输入预留跨列组头。组头只用于显示及操作，不写入媒体结果，也不产生下载任务。
- 验证等待、提取中、空结果、部分失败、停止、组内重试及其他组同时继续；重试不替换成功结果。
- 结果增加可选的 `source_order`，旧记录按首次出现顺序恢复分组，继续使用原有稳定媒体 ID。

## 界面交互

- Windows 11，980×680、1180×800，100%、125%、150% 缩放；检查首页、明暗主题、分组结果、筛选无匹配和失败组。
- 两种尺寸均没有横向滚动；组头按钮完整显示，长来源地址居中省略，悬停可查看完整地址。
- 实际点击组内选择和下载按钮，检查跨组选择、视频／音频筛选、混合画质及批量下载计划。
- 新结果插入较早的组时，后面组的控件、焦点、勾选与画质保持；进度继续按 75ms 合并，搜索按 150ms 合并。

## 刷新性能

同一组 100 条来源、300 行媒体，v0.5.1 另含 100 行组头。五轮取中位数，包括一次事件循环处理。该测量反映本机界面刷新，不代表网络提取时间。

| 场景 | v0.5.0 | v0.5.1 |
| --- | ---: | ---: |
| 重复刷新同一列表 | 11.95ms | 20.81ms |
| 连续调用状态刷新 100 次 | 36.22ms | 88.59ms |

## 回归与便携包

源码测试：66 项通过，4 项仅供打包 exe 运行；自动化维护测试另有 11 项通过。

新增真实 GUI 多链接测试：本地 HTTP 服务提供两条不同来源地址、相同标题的 MP4，分享文本包含重复地址。验证结果只生成两个来源组、两个下载任务，视频及原始音轨共四个文件直接保存到指定目录，同名自动编号，无标题子目录。

便携包回归共 7 项：后台诊断、视频与音频输出、精简 PATH 启动、完整 GUI 单链接下载、多链接分组与同名平铺输出，以及 HLS／DASH 指定画质。沿用现有构建校验与发行草稿流程，实际执行结果保存在 PR 和 Actions 中。
