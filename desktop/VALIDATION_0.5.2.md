# v0.5.2 验证记录

本版增加三种保存方式，下载内容仍由视频、音频、封面筛选及勾选决定。上游源码保持不变。

- 直接保存：验证三类文件平铺输出，解析及下载过程中没有将解析器工作目录或媒体中间目录建到成品位置。
- 按作品保存：同一作品的视频、音频和封面共用标题目录；不同作品同名时分别编号，重试继续使用原目录。
- 按类型保存：视频、音频、封面分别进入中文分类目录，只创建需要的类型。批量按钮随筛选显示相应内容。
- 设置记住上次选择，每个排队任务固定自己的保存方式，重启恢复后仍保持原设置；旧设置与任务默认平铺输出。
- 本地 HTTP 真实媒体验证三种模式、双任务并发、同名文件、原始音轨、指定画质和重复链接。
- 验证跨磁盘复制成功及中断，复制完成前不暴露目标文件；本机另实测 C 盘工作目录向 D 盘发布视频和音频。
- 三种模式均验证取消后清理临时目录与本次创建的空目录，保留原有目录及文件。
- Qt 实际窗口检查 980×680、1180×800 的首页、结果、队列和明暗主题，保存方式控件完整显示；另检查 125%／150% 缩放。

源码回归与 Windows 便携 exe 回归通过后，由功能 PR 合入 `desktop`。发行流程继续执行完整源码测试及 9 项 exe 测试，包括三种保存方式的真实 GUI 批量下载。最终结果见对应 PR 与 Actions 记录。
